# Governance Artifacts

Governance artifacts are the typed records you maintain so a sensitive activity
can be defined, operated and checked. This section covers three kinds:

- **[Definitions](/docs/artifacts/definitions/)** — what good looks like: principles, guidance, threats, controls, risks and policy
- **[Sensitive Activity](/docs/artifacts/activity/)** — the sensitive activity being governed
- **[Measures](/docs/artifacts/measures/)** — evaluation, enforcement and audit records produced as the activity runs
